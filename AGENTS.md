# Working agreement

This is an independent public-method implementation. Use invented examples only. Do not copy private financial data/code or team coursework into this repository. Attribute academic motivation separately from authorship.

Keep contract strike, expiry, quantity, multiplier and exercise style explicit. Do not label scenario revaluation as historical trading performance. Reject unsupported inputs rather than silently ignoring them. Price, Greek and portfolio changes require independent financial identities/boundaries and end-to-end tests, not only implementation-mirroring assertions.

Preserve existing output files. Never claim regulatory compliance, production adoption, executable strategy profit or model approval from software tests. Document finite-difference and tree convergence limits. No web publication claim until a usable web surface is deployed and checked.
